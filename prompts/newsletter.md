# Newsletter prompt

Entrada: diário + resumo semanal + principais commits + drafts de posts.

Produzir newsletter em Markdown com:
- Headline (curto, técnico).
- Olá (1 parágrafo curto).
- "O que aprendi esta semana" (3–5 bullets com link do diário).
- "O que construí" (commits/projetos).
- "Pensamento da semana" (1 parágrafo).
- CTA: convido resposta direta.
